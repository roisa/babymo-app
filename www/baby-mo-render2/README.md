# Baby Mo — Render 2 pose library

The second Baby Mo render series (green overall with a star, orange sleeves, yellow cuffs).
Use it alongside the first real render series in `../baby-mo-poses/`.

Framing matches `baby-mo-poses/`: 480×480 transparent WebP, feet / lowest point on y≈438
(42px floor padding), standing Mo ≈ 370px tall, centred on the body. Props stay in the frame,
so the files can be swapped for one another without CSS changes. The source renders are only
about 500px per pose, so there is no 2× (960px) version.

Where the source sheets had near-duplicates, the plain name is the best take and `-b`, `-c`, `-d`
are alternates.
